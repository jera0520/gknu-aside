강의에서 같이 한 순서 그대로예요. 집에서 다시 해 볼 때 위에서부터 따라 하세요.

준비할 것
  • 윈도 10(22H2 이상) 또는 윈도 11 PC
  • 개인 구글 계정 (학교 계정은 막혀 있을 수 있어요)
  • 안티그래비티는 만 18세 이상만 쓸 수 있어요
  • 둘 다 무료로 시작할 수 있어요 (Aside 무료: 한 달 500 크레딧)

AAside 설치

AI가 대신 눌러 주는 브라우저예요.

  1. aside.com 들어가서 Download

    Download 옆 ▾ 를 눌러 Windows x64 (Intel / AMD) 고르기

    대부분의 PC는 x64예요. 다운로드가 안 되면 Download Aside manually
  2. 받은 파일 더블클릭

    다운로드 폴더의 AsideInstaller…win-x64.exe 를 열고 화면 안내대로 설치

  3. Aside 열고 계정 만들기·로그인

    무료 플랜으로 시작하면 돼요.

B안티그래비티 설치

구글이 만든 AI 앱이에요. 이 앱이 Aside에게 일을 시켜요.

  1. antigravity.google/download → Windows

    Antigravity App 칸의 Download for x64 (CLI·IDE 말고 App)

  2. 설치하고 Sign in

    개인 구글 계정으로 로그인 → 하는 일 고르기에서 Knowledge Work → Continue

C두 앱 연결하기 (MCP)

Aside 쪽에서 「연결 도구(CLI)」를 깔고, 안티그래비티 설정 파일에 Aside를 한 줄 넣는 방식이에요.

  1. Aside 설정에서 CLI 설치

    Aside 설정의 Developer settings 에서 CLI를 설치해요. 여기에 CLI 경로가 보이면 적어 두세요.

    메뉴가 안 보이면 Aside 개발자 안내 → Windows 탭 코드를 복사해 PowerShell에 붙여 넣으세요. 설치 뒤 명령을 못 찾으면 PowerShell 창을 새로 여세요.
  2. 안티그래비티 MCP 설정 열기

    왼쪽 Customizations → Installed → 아래로 내려 MCP Servers → 위의 Copy Config File Path 로 설정 파일 경로를 복사해 메모장으로 열기

  3. 아래 내용 붙여 넣고 저장
    mcp_config.json
    {
  "mcpServers": {
    "aside": {
      "command": "aside",
      "args": ["mcp"]
    }
  }
}
    파일에 이미 다른 서버가 있으면 통째로 덮지 말고 "mcpServers" 안에 "aside" 부분만 넣으세요. Aside Developer settings에 CLI 경로가 따로 보였다면 "aside" 대신 그 경로를 넣으세요(윈도는 경로의 \ 를 \\ 로 두 번 써요).
  4. Restart

    MCP Servers 목록의 aside 옆 ⋮ → Restart

D말로 시켜서 영상 만들기

안티그래비티 채팅창에 붙여 넣으세요. 처음엔 Aside 창에서 구글 로그인을 한 번 해 줘야 해요.
